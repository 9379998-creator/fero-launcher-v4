# Task 013 — Восстановить Escape и кнопку «Загрузить»
mode: apply
push: yes

## Цель
Исправить две регрессии: Escape больше не возвращает из третьего окна к первым двум; кнопка «Загрузить» не позволяет загрузить ни один объект. Эксперименты PDF → DWG приостановить. Не менять назначение кнопок, архитектуру и внешний вид.

## Порядок и разрешённые действия
Прочитать AGENTS.md и относящиеся к задаче правила проекта. Ветка bridge — только для обмена; изменения приложения выполнять в рабочей папке main. Разрешены git status/diff/log/show, поиск и чтение исходников, журналов и тестов, редактирование относящихся к двум ошибкам файлов, запуск целевых тестов и штатной сборки. Для этой задачи явно разрешён штатный запуск приложения и его сервера для проверки интерфейса; не запускать второй экземпляр поверх рабочего и не завершать чужие процессы. Не выполнять разрушительную очистку и не трогать пользовательские данные.

## 1. Escape
Воспроизвести и установить причину. Восстановить прежний переход из третьего окна к первым двум с сохранением выбранного объекта, каталога, положения списка и состояния просмотра. Проверить фокус в просмотрщике, поиске и других элементах, конфликты клавиатурных обработчиков и модальных состояний. Не вводить глобальный перехват, нарушающий остальные действия Escape.

## 2. «Загрузить»
Воспроизвести на реальном объекте. Проверить цепочку нажатие → штатный обработчик → выбор каталога объекта → импорт → обновление интерфейса. Прежнее назначение уточнить по коду и контрактам проекта, а не придумывать новое. Проверить доступность кнопки, перекрытия, подписки и исключения — это гипотезы, не готовый диагноз. При ошибке дать понятное сообщение и подробности в журнале, без молчаливого отказа.

## Приёмка
1. В реально запускаемой пользователем сборке открыть объект и третье окно; Escape возвращает к первым двум с сохранением состояния.
2. Повторить несколько раз, меняя фокус.
3. Загрузить несколько разных реальных объектов штатной кнопкой, включая загрузку после Escape и после перезапуска приложения.
4. Добавить целевые регрессионные тесты там, где позволяет инфраструктура. Успешная компиляция не заменяет проверку интерфейса. Если GUI-проверка недоступна, явно указать это и статус partial.

## Публикация результата
Отдельный коммит на каждую исправленную регрессию в main; push origin main разрешён после проверок, без force и без чужих изменений. Если обнаружены расхождения или небезопасное состояние рабочей копии — остановиться и описать, не затирать изменения. Отчёт: .agent_bridge/outbox/013-escape-load-regressions.md в ветке bridge. Указать status: ok | partial | failed, причины обеих ошибок, изменённые файлы, хеши коммитов, точный путь реально проверенной сборки, команды с кодами возврата и фактические результаты каждого шага приёмки. Не объявлять непроверенное исправленным. Не публиковать секреты.
