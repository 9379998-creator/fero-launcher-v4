## 1. Два независимых уровня вместо разрушительной очистки
Реализовать в обычном экспорте сохранённую исходную CAD-геометрию выбранной области и отдельно производный обработанный результат. Исходный уровень должен извлекаться до фильтров штриховок, мелочи, дублей, классификации, удаления заливок и сшивки; копия уже обеднённого экспорта не подходит.
Исходный уровень: отдельные редактируемые CAD-сущности, не растр, не PDF underlay, не единый неразборный блок. Сохранять линии, кривые, прямоугольники/quads, все subpaths, закрывающие сегменты, отверстия, видимые тексты, выноски и штриховые элементы в пределах выбранного. Сохранять границы залитых областей до удаления заливки; не подменять реальную границу bbox-прямоугольником. Учитывать clipping, fill rules и преобразования исходника. Не экспортировать скрытое за PDF clipping содержимое как видимое.
Нейтральные слои PDF_RAW_GEOMETRY, PDF_RAW_FILL_BOUNDARIES, PDF_RAW_HATCH, PDF_RAW_TEXT допустимы как предлагаемые имена. Неуверенная классификация не основание для удаления: оставлять на общем исходном слое. Штриховку/заливку при возможности сохранять отдельно; если заливку нельзя передать верно — сохранять её реальные границы и явно отметить ограничение внешнего вида.
Обработанный уровень строить независимо, не меняя исходный. Исходный и обработанный наборы не должны одновременно мешать видимыми дублями: обеспечить понятное переключение видимости/отдельные представления. Для приёмки дополнительно выдать отдельные RAW.dwg и PROCESSED.dwg в одинаковой системе координат. Если обработанный уровень неполон, исходный должен быть доступен по умолчанию, а неполнота обозначена. Все исходные кривые сохранять точно подходящим типом CAD-сущности, например SPLINE; круговую аппроксимацию использовать только при проверенной погрешности, не выдавать любую Безье за дугу.

## 2. Запрет на молчаливые потери
В RAW отключить эвристическое удаление коротких линий, тонких полос, диагоналей, сомнительных дублей и элементов «неизвестного материала». Не схлопывать две стороны тонкой стенки. Не применять ограничения числа сущностей/кластеров как фильтр исходного содержимого. Не переносить координатные правила X/Y из 032 в RAW.
Составить локальный provenance-реестр source path/subpath/item → CAD handle(s), преобразование, тип и результат: сохранён, корректно обрезан рамкой/clipping, перекрыт по правилам PDF, не поддержан с явной причиной. Для текста аналогичный учёт. Число сущностей не обязано совпадать один к одному; важен учёт каждого видимого исходного элемента. Неподдержанный объект не замалчивать и не называть экспорт полным. При растре в выделении обозначить наличие растра и отсутствие восстановленной редактируемой векторной формы; не обещать универсальный конвертер.

## 3. Рамка и координаты
Сохранять только выбранную область, без padding и внешних целых текстовых блоков/выносок. Не закрывать пересечённый рамкой профиль по рамке произвольной линией. Отличать обрезанный профиль от потерянного полного. Проверить 0/90/180/270 градусов и соответствие UI/PDF/CAD, включая монтажный узел. Полный лист и эквивалентное физическое выделение не должны давать разные внутренние элементы. Сдвиг начала рамки без отсечения изделия не должен менять его форму.

## 4. Обработанный результат — без угадывания
Сохранять уже исправленную выдачу настоящего DWG и нативные DIMENSION на слое «Размерная линия». RAW хранит исходную размерную графику; производный уровень — распознанные размеры без видимых дублей. Реальные точки и measurement без подгонки override/DIMLFAC. Не объединять соседние изделия/два сечения по одному материалу. RAW не группировать весь в один неразборный объект. Замкнутые контуры производного уровня восстанавливать по структуре исходных путей/материальных областей, не повышением snap, сдвигом концов и перемычками. Не блокировать поставку полного RAW ради сложной семантики деталей; нерешённые требования PROCESSED честно обозначить partial.
