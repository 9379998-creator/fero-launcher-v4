# Task 025 — Строгая рамка, реальные размеры и контуры без штриховки
mode: apply
push: yes

## Основание и область действия
Пользователь показал выделение рамкой на странице каталога MASTERLINE 8 и результат CAD: в экспорт подтянулись длинные подписи вне выделения, размеры потерялись. Номер страницы и исходный файл по скриншоту не установлен — найти реальный PDF, страницу, точную рамку и фактический выходной DWG/DXF, не подменять прежней страницей другого узла. Зафиксировать пути, хеши, параметры, SHA генератора и воспроизведение через штатный интерфейс. Если исходников нет — остановиться с точным перечнем недостающего.
Это контракт каталожного режима: только внешние/внутренние контуры деталей, нативные размеры и артикулы внутри рамки; штриховки не выводить. Не отменять полный режим reference со штриховками из 018. Прочитать 022–024 и актуальные отчёты/код; сохранить достигнутую геометрию, разделение деталей и интерфейс, не объявлять предыдущие версии принятыми.

## 1. Рамка — строгая граница экспорта
Переносить ровно выбранную область: без скрытого crop_padding, расширения до объекта/текстового блока, подтягивания связанных подписей, полей, выносок и соседних видов извне. Проверить преобразование рамки UI→PDF с учётом zoom, поворота, CropBox, Form и clipping. Извлечение пересекающего рамку большого drawing/text block не означает разрешение экспортировать его целиком.
Геометрию обрезать по точной границе, включая линии и кривые; не экспортировать внешнюю часть пересекающего объекта. Текст фильтровать на уровне реальных строк/символов, а не целого блока: ни одна надпись извне не должна притягиваться. Для частично пересечённой надписи определить и документировать строгую политику: не выводить полную строку за рамкой и не придумывать новый смысл обрезанных слов. Страница вне рамки может анализироваться для проверки масштаба, но это не разрешение добавлять оттуда сущности.
Обрезанный рамкой профиль оставить явно неполным, не закрывать искусственно по краю рамки и не достраивать из невидимых частей. Частично выбранный размер не дополнять геометрией извне: пометить incomplete и перечислить в отчёте. Не создавать новый размер с иным измерением после обрезки. Визуальные элементы восстановленных размеров также должны укладываться в выбранную область; конфликты диагностировать, не менять рамку молча.

## 2. Размеры — отдельная семантика и слой
Восстановить реальные размерные конструкции: выносные точки/линии, размерную линию, стрелки/засечки и число. Распознавать их по совокупности геометрии и текста, не по наличию цифр. Артикулы, например цифровые коды с точками/суффиксами, не считать размерами. Не удалять размеры при фильтрации штриховок.
Каждый размер выводить нативной сущностью DIMENSION на слое DIMENSIONS. Число — семантическая часть размера, не случайная подпись; клик выбирает размер целиком, без дублирующих самостоятельных LINE/LWPOLYLINE/TEXT поверх него. Артикулы сохранять отдельными TEXT/MTEXT на ARTICLES. Контуры деталей отделить от обоих слоёв. Не удалять внутренние элементы анонимного блока, необходимые для отображения DIMENSION.
Размеры 5, 6, 20 мм пользователь привёл как примеры: проверить фактически имеющиеся значения на выбранной странице. Итоговая модель в реальных мм 1:1: соответствующее расстояние при измерении CAD должно совпадать с номиналом в пределах доказанного допуска. Проверить несколько независимых размерных пар, локальные масштабы видов, единицы, DIMLFAC и переопределения до/после DWG-конвертации. Не подгонять текст через override или множитель при неверной геометрии. Не деформировать модель при конфликте подписей: конфликт показать и оставить неопределённость. При неустановленном масштабе не выдавать молчаливый 1:1 за подтверждение.

## 3. Контуры без штриховки
В режиме catalog не выводить HATCH, отдельные линии/петли штриховки и заливочные полосы как мусорные CAD-сущности. При анализе использовать исходные заливки для восстановления материала и его границ; не удалять их до восстановления. Не выкидывать реальные наклонные грани по одному углу и не путать размерные стрелки со штриховкой.
Сохранить реальные наружные границы и камеры наружной чаши, внутренней чаши, термовставок, наружных/внутренних/средних уплотнителей и иных найденных деталей. Сохранить радиусы/пазы/кривизну без перемычек, произвольного close=True и склейки соседних стенок. Цельные границы редактируются отдельно; физические детали выбираются целиком согласно 024. Артикулы остаются читаемыми и правильно размещёнными внутри рамки. Не менять контракт полного режима reference.

## Проверки и приёмка
На реальной пользовательской странице выполнить экспорт той же рамки через интерфейс. Представить наложение PDF-выделения и выходного CAD в общей системе координат; таблицу экстентов всех классов сущностей и подтверждение отсутствия внешних надписей. Проверить малую/большую рамку, границу через длинный текстовый блок, кривую, профиль и размер; разные zoom/поворот. Не добавлять внешнюю геометрию для скрытого восстановления обрезанных объектов.
Реестр размеров: номинал PDF, фактические определяющие точки и расстояние, измерение DIMENSION, отображаемое число, слой, единицы, отклонение/допуск, статус complete/incomplete/uncertain. Проверить реальные DIMENSION, отдельные артикулы, отсутствие дублей, штриховок и утраты профильных границ. Добавить поведенческие тесты рамки на уровне примитивов/текста и классификации размер/артикул/штриховка. Сохранить регрессии 022–024, reference и интерфейса.
Создать отдельные generated_025.dxf и generated_025.dwg; проверить итоговый DWG после повторного открытия доступным CAD/API/GUI. Разделить программные тесты, измерения CAD и GUI/ручную приёмку; если не проверено — partial. Число тестов/размеров само по себе не доказательство соответствия.
