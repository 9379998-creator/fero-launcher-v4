## 2. Паспорт каждого воспроизведения

## 4. Режимы
Каталожный: удаление заливок/штриховок допустимо при сохранении настоящих границ материала, обеих сторон тонких стенок, камер и пазов. Отличие линейного вида от чёрного залитого исходника само по себе не дефект.
Полный чертёж: проверить сохранность предусмотренных режимом штриховок, текстов, выносок, геометрии. Не оправдывать потери правилами каталожной очистки. Для каждого случая установить реально выбранный режим.
