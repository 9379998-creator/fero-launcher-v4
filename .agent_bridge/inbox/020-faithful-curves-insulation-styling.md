## 1. Исправить причину смещения радиусов ДО соединения
Выбрать и пронумеровать реальные повреждённые участки профилей, стеклопакета/герметизации и утеплителя. Для каждого проследить исходный PDF-путь и контрольные точки → извлечение → общие координаты → DXF → DWG. Проверить матрицы вложенных Form, порядок преобразований, поворот страницы, смену осей/знаков, преобразование всех контрольных точек, направление обхода, параметры дуг/bulge и единицы. Это гипотезы проверки, не готовый диагноз.
Отключить маскирующую склейку при диагностике. Сначала доказать правильное положение и форму исходной кривой и соседних прямых, затем объединять только соответствующие участки. Запрещены произвольные хорды/перемычки, увеличение snap, передвижение дуги к ближайшей линии без доказательства, подгонка по абсолютным координатам, convex hull и сглаженная огибающая. Сохранять геометрию в пределах обоснованного допуска, не склеивать соседние стенки и не уничтожать пазы. ARC/bulge использовать только для действительно круговых дуг; иначе точные SPLINE либо адаптивная аппроксимация с контролем ошибки. Для каждой целевой камеры и внешней границы — отдельный выбираемый контур, правильные полости и непрерывность там, где она есть в источнике. Повторно проверить две линии герметизации и их реальное примыкание, а не факт склейки.

Сохранить отсутствие штриховки в отдельном каталожном режиме 017, не менять его контракт.
