## 2. Физика связи PDF и эталонного DWG: причины отличий и исправления

1. **Параметры печати в эталонном DWG**:
   - В пространстве Model эталона прочитаны атрибуты печати виртуального плоттера `DWG To PDF.pc3`:
     - Окно печати: `plot_window = (545226.65, -64090.04) -> (546259.96, -63350.88)` (размер 1033.31 × 739.16 мм);
     - Угол поворота плоттера: `plot_rotation = 1` (90°);
     - Масштаб плоттера: `scale_denominator = 3.5197922` (масштаб 1:3.5198 для вписывания в лист A4);
     - Бумага: `paper_width = 210.0, paper_height = 297.0` мм.
2. **Ориентация страницы и компенсация поворота**:
   - PDF сгенерирован плоттером в портретной ориентации с поворотом 90°, после чего в словарь страницы добавлен атрибут `/Rotate 270`.
   - Векторные пути `get_drawings()` и координаты текста хранятся в неразогнутом виде (`px` по высоте 842, `py` по ширине 595).
   - Преобразование координат для возврата в правильное горизонтальное положение:
     - $\text{CAD\_X} = (\text{py} - 50.0) \times \text{total\_scale}$;
     - $\text{CAD\_Y} = (\text{px} - 150.0) \times \text{total\_scale}$.
   - Это даёт правильное физическое расположение: рама окна вертикально, отлив слева, внутренняя отделка справа, стена снизу.
3. **Автокалибровка масштаба 1:1 мм строго из PDF**:
   - В PDF размерная линия 87 имеет расстояние между засечками $70.080\text{ pt} \implies 87.0 / 70.080 = 1.24144\text{ мм/pt}$.
   - Размерная линия 76 имеет расстояние между засечками $61.200\text{ pt} \implies 76.0 / 61.200 = 1.24183\text{ мм/pt}$.
   - Размерная линия 3 имеет расстояние между засечками $2.400\text{ pt} \implies 3.0 / 2.400 = 1.25000\text{ мм/pt}$.
   - Согласованный масштабирующий множитель: $\mathbf{3.519}$ (совпадает с `scale_denominator = 3.51979` AutoCAD до тысячных долей).
4. **Смена контракта со штриховками (в отличие от Задания 017)**:
   - В Задании 018 штриховки сохранены и распределены по выделенным слоям:
     - `06_ШТРИХОВКА_СТЕНЫ` (499 линий диагональной штриховки 45°);
     - `06_ШТРИХОВКА_УТЕПЛИТЕЛЬ` (1618 линий и петель минеральной ваты/утеплителя);
     - `06_ШТРИХОВКА_ОБЩАЯ` (621 линия герметиков и вспомогательных структур).
   - Каталожный режим 017 (Zero Hatch) сохранён как отдельный режим (`mode="catalog"`), не смешиваясь с режимом полного чертежа (`mode="reference"`).
5. **Компиляция нативного DWG**:
   - Консольный модуль AutoCAD 2024 `accoreconsole.exe` выполняет headless команду `_SAVEAS 2018`, собирая итоговый файл `uzel_po_nizu_okna_generated_018.dwg` (325 567 байт).

## 4. Необратимо утраченные в PDF сведения

1. **Глобальные проектные координаты**:
   - В эталонном DWG узел нарисован со смещением $X \approx 545\,000\text{ мм}, Y \approx -63\,000\text{ мм}$. При выводе в PDF виртуальный плоттер отсёк глобальный базис и перенёс геометрию в координаты листа A4 `(0..842, 0..595)`.
   - В восстановленном чертеже координаты нормализованы к локальному нулю `(0, 0)` с физическими габаритами $864 \times 399\text{ мм}$.
2. **Семантические имена блоков**:
   - Исходные имена внутренних блоков AutoCAD (например, `4.2x16JPMT`, `Стеклопакет 46mm`) в PDF не сохраняются: PDF содержит чистые векторные кривые `l`, `c`, `re`. Они восстановлены как независимые редактируемые контуры на соответствующих слоях (`01_ПРОФИЛИ_ОКНА`, `02_ОТЛИВ_МЕТАЛЛ`, `03_ТЕРМОМОСТ`, `04_УПЛОТНИТЕЛИ_ГЕРМЕТИКИ`, `05_СТЕКЛОПАКЕТ`).
