## 6. Сквозная интеграция и контракт API / UI

В `app/backend/server.py` обработчик эндпоинта `/api/pdf/export-cad` обновлен для гарантированной сквозной выдачи бинарного DWG:

```python
# app/backend/server.py
options = {
    "crop_box": crop_box,
    "mode": mode,
    "scale": scale,
    "compile_dwg": True,  # Гарантированная компиляция в binary DWG через AutoCAD accoreconsole
}
res = export_pdf_page_to_cad(..., options=options)
if not res.get("dwg_path") or not os.path.exists(res["dwg_path"]):
    raise RuntimeError(f"AutoCAD DWG compilation failed: {res.get('error')}")

return jsonify({
    "ok": True,
    "format": "dwg",
    "cad_path": res["dwg_path"],
    "dxf_path": res.get("dxf_path"),
    "dwg_path": res["dwg_path"],
    ...
})
```

- **Исключен молчаливый откат**: если компиляция через `accoreconsole` не удалась, сервер не маскирует сбой и не выдает DXF с расширением `.dwg`, а возвращает явную ошибку `500` с описанием сбоя компилятора.
- **Подлинность формата**: проверяется сигнатура заголовка файла (`b"AC1032"`).
