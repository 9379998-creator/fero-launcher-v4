## 4. Проверка B — Статус обратного вывода в PDF

- **Инструмент**: Autodesk AutoCAD 2024 (`accoreconsole.exe`).
- **Ограничение консольного режима**: Консольный процесс `accoreconsole.exe` запускается в фоновом режиме без графической подсистемы Windows Display Driver. Команды печати `-PLOT` и `EXPORTPDF` в headless-режиме требуют инициализации виртуального контекста отображения (GDI/DirectX device), в противном случае процесс ожидает интерактивного устройства вывода.
- **Статус проверки B**: `partial` (в строгом соответствии с указанием п. 33 ТЗ: *«Если обратный вывод недоступен — partial и точное ограничение; не заменять его изображением DXF, объявленным проверкой DWG»*).
- **Прямая верификация DWG**: Выполнена методом математического и топологического анализа структуры бинарного DWG/DXF через `ezdxf` с проверкой нативных дескрипторов, координат и замкнутости полилиний.
