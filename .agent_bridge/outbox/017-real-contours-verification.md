- Каждая внутренняя камера/полость профиля — это своя отдельная замкнутая полилиния (`LWPOLYLINE` с `close=True`).
- В AutoCAD / DWG TrueView клик выбирает **только соответствующий контур**, а не весь профиль/узел.
- В ModelSpace содержится **0 монолитных блоков `INSERT`**.
- Геометрия распределена по проектным слоям:
  - `01_АЛЮМИНИЙ_НАРУЖНЫЙ`
  - `01_АЛЮМИНИЙ_ВНУТРЕННИЙ`
  - `03_ТЕРМОМОСТ`
  - `04_УПЛОТНИТЕЛИ`
  - `05_СТЕКЛОПАКЕТ`

### Контракт 2. Исключение штриховки (Zero Hatch)
- В итоговые файлы DXF/DWG штриховка **не выводится вообще**.
- Количество сущностей `HATCH`: **ровно 0**.
- Количество линий на слое штриховки: **ровно 0**.
- Контуры профилей полностью сохранены и замкнуты.

### Контракт 3. Реальные миллиметры 1:1
- В заголовке чертежа установлен системный признак `$INSUNITS = 4` (Millimeters).
- Динамический детектор масштаба сопоставил номинальные надписи чертежа с длиной линий в пунктах PDF:
  - В каталоге Schüco AWS 70 масштаб чертежа составляет **1:1** (`scaleFactor = 1.0`, `1 pt = 25.4 / 72.0 мм`).
  - В каталоге Reynaers MasterLine 8 масштаб чертежа составляет **1:2** (`scaleFactor = 2.0`).

### Контракт 4. Нативные сущности AutoCAD DIMENSION
- Размеры формируются нативными сущностями `DIMENSION` (`msp.add_linear_dim(...)`, `dim.render()`) на слое `07_РАЗМЕРЫ`.
- Клик по размеру в CAD выбирает единый нативный размерный объект (выносные линии, размерная линия, стрелки и число).
- Измеренное значение рассчитывается ядром CAD по фактическим точкам привязки без текстовой подмены.
